# GF-Engineers — Ιστοσελίδα Τεχνικού Γραφείου

Landing page για το **Τεχνικό Μελετητικό Γραφείο GF-Engineers** — Χρήστου Γεωργακόπουλου & Αθανασίου Φουντά, με έδρα την Αμαλιάδα Ηλείας.

## Περιεχόμενα

- `index.html` — Η πλήρης σελίδα (HTML, CSS & JavaScript σε ένα αρχείο).
- `logo-mikro.jpg` — Λογότυπο γραφείου.
- `photo-1.webp`, `photo-2.webp`, … — Φωτογραφίες έργων για το gallery.

## Gallery έργων

Το gallery ανιχνεύει **αυτόματα** τα αρχεία `photo-1`, `photo-2`, `photo-3`, … σε κάθε
φόρτωση της σελίδας (καταλήξεις `.webp` / `.jpg` / `.jpeg` / `.png` / `.avif`).

Για να προσθέσεις νέα φωτογραφία, απλώς ανέβασε ένα αρχείο με το **επόμενο διαθέσιμο**
όνομα (π.χ. `photo-6.webp`) — εμφανίζεται μόνο του, χωρίς αλλαγή κώδικα. Κράτα την
αρίθμηση συνεχόμενη (χωρίς μεγάλα κενά) και προτίμησε συμπιεσμένο `.webp` έως ~1600px.
